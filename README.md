# הבית שלנו: משימות, מטלות בית והוצאות משותפות

אפליקציית רשת להתקנה על האייפון (PWA). יש בה:
- **היום**: כל מה שמחכה לך היום במקום אחד
- **בית**: מטלות בית חוזרות, משותפות לשניכם. מכל מטלה רואים מתי בוצעה לאחרונה ומי ביצע אותה
- **אישי**: משימות והרגלים. כל אחד רואה רק את שלו
- **הוצאות**: הוצאות משותפות, סיכום חודשי וחישוב "מי מעביר למי" לפי חלוקה של חצי-חצי

## הרצה מקומית (מצב הדגמה)
```
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```
פתחו את http://localhost:8080. כל עוד `config.js` ריק, הנתונים נשמרים רק בדפדפן.

## חיבור לענן (פעם אחת, כ-10 דקות)

### 1. Supabase: מסד הנתונים והתחברות
1. נרשמים ב-https://supabase.com, לוחצים **New project**, בוחרים שם וסיסמה ומחכים שהפרויקט יוקם.
2. בתפריט: **SQL Editor** ← **New query**. מדביקים את כל התוכן של `supabase/schema.sql` ולוחצים **Run**.
3. **Authentication** ← **Sign In / Providers** ← **Email**: מכבים את **Confirm email**. כך אפשר להתחבר מיד בלי לאשר מייל.
4. **Project Settings** ← **API**: מעתיקים את **Project URL** ואת המפתח **anon public** לתוך `config.js`.
   (המפתח הזה ציבורי מטבעו. ההגנה על הנתונים היא בכללי האבטחה שבקובץ ה-SQL.)

### 2. העלאה לאינטרנט
הדרך הפשוטה היא **Netlify Drop**: https://app.netlify.com/drop
גוררים לשם את כל תיקיית הפרויקט ונרשמים, כדי שהאתר לא יימחק. מתקבלת כתובת כמו `https://something.netlify.app`.
בכל עדכון גוררים שוב את התיקייה.

### 3. התקנה על האייפון
1. פותחים את הכתובת ב-**Safari**.
2. כפתור השיתוף ← **הוסף למסך הבית**.
3. נרשמים. הראשון שנרשם יוצר "בית חדש" ומקבל קוד בן 6 תווים (מופיע גם בהגדרות, תחת העיגול עם האות).
4. בן/בת הזוג נרשמים בטלפון שלהם ובוחרים **הצטרפות עם קוד**.

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `index.html`, `styles.css` | המסגרת והעיצוב |
| `app.js` | המסכים, הטפסים והלוגיקה |
| `store.js` | שכבת הנתונים: מצב הדגמה (localStorage) או Supabase |
| `config.js` | פרטי החיבור ל-Supabase |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה כאפליקציה ועבודה בלי רשת |
| `supabase/schema.sql` | הטבלאות וכללי האבטחה |
