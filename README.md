# הבית שלנו: משימות, מטלות בית והוצאות משותפות

אפליקציית רשת להתקנה על האייפון (PWA), לזוג שחולק בית. כל לשונית יושבת על תמונה של הבית, שמשתנה לפי מה שקורה:
- **היום**: כל מה שמחכה לך היום. החלונות של הבית נדלקים אחד אחד ככל שמסיימים.
- **בית**: מטלות בית חוזרות, משותפות לשניכם, לפי חדרים. חדר שאין בו מטלות שמחכות מואר. לחיצה על חדר מסננת את הרשימה.
- **אישי**: משימות והרגלים, כל אחד רואה רק את שלו. העציץ גדל לפי מספר הימים שבהם סימנת הרגל (3, 7, 14, 30 ו-60 ימים), ולא נובל אם מפספסים.
- **הוצאות**: הוצאות משותפות, סיכום חודשי, ו"מי מעביר למי" לפי חלוקה של חצי-חצי. המאזניים נוטים לצד של מי ששילם יותר.

גוררים שורה הצידה כדי לסמן "בוצע" או למחוק. הלחיצה על הכפתור שנחשף היא שמבצעת.

כתובת האתר: https://amiorto.github.io/home-app/

## התקנה על האייפון
1. פותחים את הכתובת ב-**Safari** (לא מתוך וואטסאפ).
2. כפתור השיתוף ← **הוספה למסך הבית**. מעכשיו נכנסים רק דרך האייקון.
3. נרשמים. הראשון שנרשם יוצר בית חדש ומקבל קוד בן 6 תווים (מופיע גם בהגדרות, בגלגל השיניים).
4. בן/בת הזוג נרשמים בטלפון שלהם ובוחרים **הצטרפות עם קוד**.
5. הגדרות ← **הפעלת התראות**.

כל זוג אחר שנרשם מאותו קישור יוצר בית משלו, נפרד לגמרי.

## העלאת גרסה
האתר מתארח ב-GitHub Pages: כל `git push` לענף `main` מתפרסם תוך כמה דקות.
בכל שינוי מעלים את `APP_VERSION` ב-`app.js` ואת `CACHE` ב-`sw.js`. המספר מופיע בתחתית ההגדרות, וכך יודעים איזו גרסה רצה בטלפון.
אם הטלפון מציג גרסה ישנה, סוגרים את האפליקציה לגמרי ופותחים שוב.

## הרצה מקומית
```
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```
פותחים את http://localhost:8080. האפליקציה מתחברת לאותו מסד נתונים כמו האתר.
למצב הדגמה, עם שני משתמשים מדומים ונתונים שנשמרים רק בדפדפן, מרוקנים זמנית את `SUPABASE_URL` ב-`config.js` (ולא מעלים את השינוי).

## הענן: Supabase
מסד הנתונים, ההתחברות, הסנכרון בין הטלפונים וההתראות יושבים ב-Supabase.
אם צריך להקים פרויקט מחדש, אלה הצעדים, לפי הסדר:
1. **New project** ב-https://supabase.com.
2. **SQL Editor**: מריצים את `supabase/schema.sql`, ואחריו את `supabase/notifications.sql`.
3. **Authentication** ← **Sign In / Providers** ← **Email**: מכבים את **Confirm email**.
4. **Project Settings** ← **API**: את **Project URL** ואת המפתח הציבורי (publishable/anon) מעתיקים ל-`config.js`. המפתח הזה ציבורי מטבעו, וההגנה על הנתונים היא בכללי האבטחה שבקבצי ה-SQL.
5. **התראות**:
   - יוצרים זוג מפתחות VAPID. המפתח הציבורי נכנס ל-`config.js`. את שני המפתחות שומרים ב-**Edge Functions** ← **Secrets** בשמות `VAPID_PUBLIC_KEY` ו-`VAPID_PRIVATE_KEY`.
   - **Edge Functions** ← **Deploy a new function** בשם `notify`, עם התוכן של `supabase/functions/notify/index.ts`, ואז מכבים את **Verify JWT** בהגדרות הפונקציה.
   - **SQL Editor**: מריצים את `supabase/notify-schedule.sql`, שמפעיל את הפונקציה כל רבע שעה.

ערכים סודיים, כמו המפתח הפרטי של ההתראות, לא נכנסים לגיטהאב. `supabase/secrets.txt` מוחרג ב-`.gitignore`.

## ההתראות
הפונקציה `notify` רצה כל רבע שעה ושולחת כל התראה יומית פעם אחת, בחלון השעות שלה (שעון ישראל):

| התראה | חלון | נשלחת רק אם |
|---|---|---|
| סיכום בוקר | 8:00 עד 11:00 | יש משהו להיום |
| מה שעוד מחכה להיום | 18:00 עד 21:00 | נשאר משהו פתוח |
| תזכורת להרגלים | 20:30 עד 23:00 | יש הרגל שלא סומן |

בנוסף, כשאחד מסמן מטלה או משימה משותפת כבוצעה, או מוסיף הוצאה, השני מקבל עדכון מיד.
כל אחד יכול לכבות כל סוג בהגדרות. באייפון ההתראות עובדות רק מהאייקון במסך הבית, ב-iOS 16.4 ומעלה.

## מבנה הקבצים
| קובץ | תפקיד |
|---|---|
| `index.html`, `styles.css` | המסגרת והעיצוב |
| `app.js` | המסכים, הטפסים, ההחלקות וההרשמה להתראות |
| `parse.js` | הבנת משפט חופשי בהוספה המהירה (+ או מיקרופון) |
| `store.js` | שכבת הנתונים: מצב הדגמה (localStorage) או Supabase |
| `config.js` | פרטי החיבור ל-Supabase והמפתח הציבורי של ההתראות |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה כאפליקציה, עבודה בלי רשת וקבלת התראות |
| `images/` | תמונות הרקע: הבית (כבוי/דולק), החתך, שלבי העציץ ומצבי המאזניים |
| `supabase/schema.sql` | הטבלאות וכללי האבטחה |
| `supabase/notifications.sql`, `notify-schedule.sql` | טבלאות ההתראות והתזמון |
| `supabase/functions/notify/` | הפונקציה ששולחת את ההתראות |
| `tools/serve.ps1` | שרת להרצה מקומית |
